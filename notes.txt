Basic Tags
---------------------
1. p --> paragraph --> It will display static information about the product , person or any object.  

2. img ---> if i want to take images on web pages than i can use the tag called <img />
			The img tag require some attributes that are listed below,
				a) src --> source --> image location
				b) alt --> alternative text 
				c) width --> 
				d) height 
				e) map 

3. a --> anchor tag --> To navigate between the pages. I want to navigate(switch) home page to about page. 

Syntax:
----------------------
<a href="path" target="_self, _blank">About</a>

href ---> hypertext reference


4. pre: pre formatted text. We want to use as it is structure.

html entites  --> https://www.toptal.com/designers/htmlarrows/symbols/

5. marquee: If i want to move text or images or any object from left to right, right to left, top to bottom or bottom to top than i can use the marquee tag 

The marquee has some attributes that are listed below,
	1) direction --> left, right, up, down 
	2) scrollamount --> It controls the speed. 
	3) javascript event --> onmouseover --> to stop current object 
	4) javascript event --> onmouseleave --> to start current object

6. mark: This tag can be used in to highlight text.

Note: Every html element has style.

7. span: span is working as container.
8. <b></b> and <strong></strong> --> to make the text bold
9. <i></i> and <em></em>  --> to make text itelic
10. <u></u> to draw the underline
